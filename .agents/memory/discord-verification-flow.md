---
name: Discord verification flow
description: The user-selected new-member verification approach for this Discord bot.
---

**Rule:** Keep verification button-based: an administrator posts a panel, and the button grants the selected member role.

**Why:** The user chose a button that assigns a role instead of a CAPTCHA or reaction.

**How to apply:** Preserve the role-based button flow and its restart persistence unless the user asks to change verification methods.
