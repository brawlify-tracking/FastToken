description: The user-approved setup and privacy behavior for customer vouches in this Discord bot.

**Rule:** Configure the destination with an in-Discord administrator command instead of adding a web dashboard. A staff member starts each request in a ticket; the next customer's text is posted without Discord attribution.

**Why:** The user approved the simple setup flow and automatic anonymous reposting.

**How to apply:** Preserve this in-Discord setup approach and anonymized, single-response forwarding unless the user asks to change it.
