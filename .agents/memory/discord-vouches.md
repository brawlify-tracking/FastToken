---
name: Discord vouch flow
description: The user-approved setup and privacy behavior for customer vouches in this Discord bot.
---

**Rule:** Configure the destination with an in-Discord administrator command instead of adding a web dashboard. A staff member starts each request in a ticket; the customer chooses a 1–5 star rating, then sends a text vouch that is posted with their Discord name and avatar. Explain the public identity and rating flow in both French and English.

**Why:** The user requested attributed vouches with a rating and approved the simple in-Discord setup.

**How to apply:** Tell customers their name and avatar will be public before they submit; preserve the in-Discord setup unless the user asks for a dashboard.
